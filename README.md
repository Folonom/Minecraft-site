# CraftStore — магазин Minecraft

Статичный сайт-магазин в стиле Minecraft: панорама главного меню, кнопки и панели как в GUI игры,
корзина в виде инвентаря, уведомления как «достижения», полоска опыта при прокрутке.
Никаких сборщиков и зависимостей — обычные HTML, CSS и JS.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` выкладывает сайт при каждом пуше в ветку.
Один раз включите: репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**,
затем запустите workflow (вкладка Actions → Deploy to GitHub Pages → Run workflow).
Адрес сайта: `https://<пользователь>.github.io/<репозиторий>/`.

## Структура

```
index.html        разметка страницы
css/style.css     все стили (панели, кнопки, слоты, тултипы, адаптив)
js/data.js        каталог: товары, цены, категории, промокоды, фразы «splash»
js/app.js         фильтры, корзина (localStorage), промокод, оформление, уведомления
assets/fonts      Monocraft (SIL OFL) — латиница + кириллица
assets/img        панорама, изометрические иконки блоков, лица мобов, favicon
assets/textures   ванильные текстуры Minecraft 1.21: блоки, предметы, GUI-спрайты, скины мобов
```

## Как менять содержимое

- **Товары и цены** — `js/data.js`, массив `products` (`price`, `oldPrice`, `badge`, `features`, иконка `art`).
  Скидка-плашка «−20%» считается автоматически из `oldPrice`.
- **Иконки**: `['item', 'diamond']` берёт `assets/textures/item/diamond.png`,
  `['block', 'grass']` — изометрический блок `assets/img/blocks/grass.png`.
- **Промокоды** — `promos` в `js/data.js` (в демо работает `CREEPER`, −10%).
- **Тексты, контакты, FAQ** — `index.html`. Адрес `support@example.com` и часы работы — заглушки.

## Что нужно доделать для настоящих продаж

Сайт полностью клиентский. Форма оформления заказа **демонстрационная**: она проверяет поля и показывает
«Заказ принят», но платёж не проводит и ключ не выдаёт (это честно написано в интерфейсе).
Чтобы продавать, нужен сервер: в `js/app.js` найдите комментарий
«Здесь должен быть запрос к вашему серверу / платёжной системе» и отправьте туда заказ
(email, состав корзины, промокод), а выдачу ключей и проверку цен делайте на стороне сервера —
цены из `data.js` доверять нельзя.

Также проверьте актуальность цен, составов коллекций и юридических текстов перед запуском.
