FAQ

Частые вопросы

Что я получу после покупки?

Код активации для выбранного товара. Его нужно ввести в аккаунте Microsoft, после чего игра появится в лаунчере Minecraft.

Нужен ли аккаунт Microsoft?

Да. Для запуска Minecraft нужен бесплатный аккаунт Microsoft — старые аккаунты Mojang уже перенесены на него.

На каких устройствах работает издание для ПК?

Java Edition запускается на Windows, macOS и Linux, Bedrock Edition — на Windows 10/11. Для консолей и смартфонов игра покупается отдельно в их магазинах приложений.

Что такое Minecoins и Realms?

Minecoins — внутриигровая валюта для покупок в Marketplace (скины, миры, аддоны) в Bedrock Edition. Realms — приватный сервер от Mojang для игры с друзьями.

Можно ли играть с друзьями?

Да: на серверах, в Realms или по локальной сети. Java и Bedrock — разные версии игры, и напрямую между собой их игроки не встречаются.
